# 远程桌面应用键盘直通说明

## 背景

在 Android / ColorOS 上使用外接键盘连接远程桌面（例如 Microsoft 远程桌面 / Windows App，
包名 `com.microsoft.rdc.androidx`）时，会发现一部分 Windows 快捷键失效：

| 按键 | Android 系统默认行为 |
| ---- | -------------------- |
| 单独按 Win(⊞ / Meta) | 打开最近任务 |
| `Alt + Tab` | 打开最近任务 |
| `Win + Space` / `Alt + Shift` | 切换输入法 / 键盘布局 |
| `Home` / `AppSwitch` | 回到桌面 / 最近任务 |
| ColorOS 自定义多媒体键盘按键 | 打开全局搜索等 |

原因是这些按键在**系统进程**里就被 `PhoneWindowManager` 拦截并消费了，根本没有分发给前台
的远程桌面应用，自然也无法通过 RDP 协议转发到远端 Windows。

## 实现原理

本模块运行在系统框架（`android` / system_server 进程）中，Hook 输入分发链路：

```
InputDispatcher (native)
      │
      ▼
com.android.server.wm.InputManagerCallback      ← Hook：最可靠的单点
      │  interceptKeyBeforeQueueing / interceptKeyBeforeDispatching
      ▼
com.android.server.policy.PhoneWindowManager    ← Hook：兜底 + 布局切换
      │  （ColorOS 扩展 PhoneWindowManagerExtImpl）
      ▼
前台应用（com.microsoft.rdc.androidx）
```

当**前台应用属于远程桌面白名单**时：

- `interceptKeyBeforeQueueing` 返回 `ACTION_PASS_TO_USER`（放行给应用）；
- `interceptKeyBeforeDispatching` 返回 `0`（立即分发）；
- `dispatchUnhandledKey` 返回 `null`（不做系统兜底）；
- `handleSwitchKeyboardLayout` / `sendSwitchKeyboardLayout` 直接短路（不切换布局）。

其中 `电源键` 与 `音量键` 始终保留系统行为，避免影响关机、调音量等基础操作。

前台应用的判断优先读取 `PhoneWindowManager.mDefaultDisplayPolicy.mFocusedApp`
（无锁、开销极小），失败时回退到 `ActivityTaskManager.getFocusedRootTaskInfo()`。

## 白名单

默认包含以下包名（可在 `RdpKeyboardHook#TARGET_PACKAGES` 中增删）：

- `com.microsoft.rdc.androidx`（Windows App / 新版 Microsoft 远程桌面）
- `com.microsoft.rdc.android`（旧版 Microsoft Remote Desktop）
- `com.microsoft.rdc.android.beta`
- `de.freerdp.afreerdp`、`com.freerdp.afreerdp`（FreeRDP）
- `com.realvnc.viewer.android`（RealVNC）

## 使用方式

1. 在 LSPosed 中把本模块作用域勾选为「系统框架（android）」；
2. 重启一次系统（首次激活需要）；
3. 打开远程桌面应用，外接键盘即可正常使用 Win、Alt+Tab 等快捷键。

## 调试

模块日志 TAG 为 `RdpKeyHook`，可在 LSPosed 日志中查看
`hooked ...` 与 `pass-through ...` 记录确认是否生效。
